# Results

`Invoke-Demo.ps1` writes this folder from SQL Server output.

| File | Contents |
| --- | --- |
| `MEASUREMENTS.md` | STATISTICS IO/TIME and statement counters captured during the run |
| `VALIDATION_REPORT.md` | Environment, configuration, row counts, test totals, and unverified items |
| `raw/` | Script logs, including the statistics message log |

Figures in these files are copied from that run. They are not a performance guarantee for other hardware, cache states, or data sizes.
